# 📋 Projeto CRM

Sistema de gestão de relacionamento com clientes desenvolvido em Python.

## ✨ Funcionalidades

- Cadastro de clientes
- Registro de vendas
- Envio de e-mails automáticos
- Notificações via Telegram
- Integração com Google Sheets

## 🛠️ Tecnologias

- Python
- Flask
- Google Sheets API
- Automação com n8n
- Visual Studio Code

## 📁 Estrutura

```
crm-projeto/
├── app.py
├── folhas.py
├── requisitos.txt
├── .env
└── credentials.json
```
